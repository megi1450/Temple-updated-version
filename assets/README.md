# Asset library

- `branding/logos/` — temple logo and identity files.
- `hero/` — homepage and supporting visual backgrounds, including the licensed diya photograph.
- `gallery/` — original temple photographs grouped by ceremony or occasion.
- `events/annual-day/` — annual-day celebration photographs.
- `ui/loader/` — existing loading animation used by legacy workflows.

Original temple photographs are retained. External assets are documented in `../ASSET_CREDITS.md`. Use the actual temple photographs for temple-specific history and events; generic stock imagery is only supporting decoration.
